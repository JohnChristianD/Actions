## Strict theorem ordering

The strict ordering is algebraic, not statistical.

For the retained probability family, Flat Dyadic is maximal because its support theorem is universal over the entire Int8 code space. Any theorem relying only on ±1 generation and zero support is strictly weaker than universal one-step code support: the latter immediately supplies every individual code as a one-step support witness, while the former only guarantees paths generated by repeated unit moves.

For methods, the concrete bridge theorem is `Exotic/ERL/FullCoupled/NoisyNetRepresentationProjection.agda`. Define the representation boundary by

`softsignGatedForward x = softsignQ8 (signReLUQ8 x)`.

The file proves:

- `toRepresentation ∘ fromRepresentation = id`;
- every `softsignGatedStep` lifts to a `NoisyNetStep`;
- every `NoisyNetStep` projects to a `softsignGatedStep`;
- representation irreducibility, self-loop, and period-one;
- full coupled Noisy-Net irreducibility and self-loop;
- two distinct GateParams can have exactly the same projected representation signal.

Thus the Noisy-Net result is a genuine strict state extension of the softsign-gated representation theorem, rather than a larger witness record. A representation-only theorem cannot account for the hidden GateParams fiber; whole-state irreducibility needs the explicit projection/lift bridge.

MR15 and OpenES still have their finite exploration theorem abstractions, but they do not yet have production-state projection/lift theorems into this same softsign-gated boundary. Therefore the repository does not assign them a false strict cross-method rank.

The maximal theorem corner on the presently connected axes is consequently:

`NoisyNet × FlatDyadic`.

## Finite-state theorem discipline

For a transition relation `_—→_`:

`Irreducible = ∀ s t → Reach _—→_ s t`.

`SelfLoop = ∀ s → s —→ s`.

The reusable sufficient package is `Irreducible × SelfLoop -> PeriodOne`.

Exploration-only reachability does not substitute for learner+EA reachability. Noisy Nets is already modeled on the coupled learner state; MR15 and OpenES remain explicit finite kernel abstractions until production transition wiring is closed.

## CHAD and activation composition

CHAD proves the correctness of a differential/VJP interface for a defined computation. Normalization, support, irreducibility, communicating classes, and period remain separate finite-state theorems.

The repository has an exact `CHADOperator` composition theorem in `Exotic/efficient_chad/Int8.agda`. It composes finite operators in the intended order:

`signReLU8 -> softsign8 -> GateNN -> Pi`.

External literature supports Möbius-composition closure in neural-network settings, but that does not establish that this repository's quantized `signReLUQ8` or `softsignQ8` are themselves Möbius operators. The local Agda theorem remains conditional on concrete finite Möbius witnesses.
