# 2026-09-23 finite-carrier transport promotion

The exact transport family was promoted out of the obsolete `Fin n` scaffolding on
`repair/fin-prune-auto-merge-2026-09-23`.

Canonical theorem nodes:

- `ExactFunctionIsomorphismTransportTheorem`
- `ExactRecurrentFunctionTranslationTheorem`
- `POMDPExactTransport`
- `GeneralizedRepresentationTransportCompositionTheorem`

The first theorem transports an arbitrary function between arbitrary representation
carriers through explicit `StateIsomorphism` witnesses. The recurrent theorem consumes
that generalized function transport. The POMDP theorem keeps transition, observation,
and reward semantics explicit while making state/action/observation representation
carriers arbitrary Sets.

The connected composition theorem consumes all three generalized surfaces, so the
Mercury theorem graph has a real Agda dependency path rather than a synthetic edge.
The old finite theorem names were removed from the strict Dhall semantic contract,
theorem-graph search list, README relationship graph, and the finite-pruning metadata.

This is not a claim that all finite probability semantics should become infinite-domain
theorems. The finite probability/belief surfaces remain separate where finiteness is
part of the mathematics. The promotion removes only accidental `Fin n` dependence
from exact representation transport.

Verification boundary: the canonical proof authority remains Agda `--safe`; the
e-graph is discovery/dependency infrastructure and must be regenerated by the normal
Mercury verification lane before CI is called green.
