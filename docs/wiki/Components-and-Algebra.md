## Algebraic forms actually used

### Finite carrier

`Int8` is a wrapper around `Fin 256`.

Arithmetic is defined on natural-number codes and reduced modulo 256. No generic `Ring Int8` interface is imported or proved.

### Products

Nested products encode small fixed-width vectors such as:

- `IntVec4`
- `WalshVec4`
- `Int8Vec4`
- `Int8WalshVec4`

### Sum-like finite data

The implementation uses Agda data declarations for closed alternatives:

- `Signed`
- `HardSign8`
- `Phase4`
- `BoolLike`

Pattern matching gives total definitions over these finite carriers.

### Endomorphism composition

`GRUAction` packages state-to-state functions.

`composeGRUAction` is associative, proved by `refl`.

`identityGRUAction` is present explicitly. The current source does not wrap this in the standard-library `Monoid` interface, so the documentation treats it as monoid-shaped composition rather than as a registered algebraic instance.

### Equivalence relation surface

`GRUEquivalent` is equality of the persistent projection:

`persistentGRU s == persistentGRU t`.

The repository proves reflexivity and that `gruStep` respects this relation.

### Finite witness structures

`PowerOfFour` is an inductive witness of a width being generated by repeated multiplication by four.

`FiniteRational` is a concrete record of sign, numerator, and denominator, not a bundled field/ring.

### Equality as the main law language

The canonical proof layer relies heavily on propositional equality:

`_≡_`, `refl`, `sym`, `trans`, `cong`, `subst`.

This is why many composition theorems are definitionally exact and close with `refl`.

## Faithfulness boundary

The environment layer is "faithful" in the following formal sense:

- action spaces are finite and typed;
- environment transition is an explicit function;
- episode state is carried without an untyped side channel;
- finite map predicates are exact source definitions;
- metrics are defined from the actual episode result.

The formalization does not prove that these finite environments are semantically identical to any external implementation. That stronger property would require a separate correspondence relation and proof against the external source/model.
