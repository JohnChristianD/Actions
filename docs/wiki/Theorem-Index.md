### Finite TSTS endogenous connected composition

The active meta-search theorem is now TSTS-only:

- `FiniteTSTSBranch`
- `FiniteTSTSPosterior`
- `finiteTSTSSelect`
- `finiteTSTSSelectedProbe`
- `finiteTSTSSelectedTarget`
- `finiteTSTSReward`
- `finiteTSTSNextPosterior`
- `finiteTSTSClosedStep`
- `FiniteTSTSEndogenousConnectedTheorem`
- `finite-tsts-endogenous-connected-theorem`

The finite composition is:

`posterior sample -> branch selection -> exact learner probe -> endogenous Watkins target -> posterior reward/update -> GRU/F4 tell`

The selected branch is one of three endogenous learner perturbations: Watkins signal, F4/L2 optimizer state, or GRU state. The TSTS reward is taken directly from the exact canonical Watkins target after the selected probe. Thus the search score is not an external fitness function: it is a value generated by the learner's own endogenous feedback and then fed back into the search posterior witness.

For the F4/L2 branch, the theorem expands the selected target to expose the dependency on:

`thetaQ + probe + L2 correction + attention + GRU feedback + q-log feedback`

while preserving the NormPair observable and persistent-GRU quotient through the canonical learner step.

This is a repository-local finite semantic specialization of the TSTS role. It is not a reproduction of the probabilistic TSTS runtime, and the published TSTS regret theorem is not claimed for this deterministic finite construction.
